# 우리의 작은 회사

React + Three.js 기반의 로컬 상태 3D 오피스 시뮬레이션입니다. 서버, AI, 로그인 없이 동작합니다.

## 실행

```sh
npm install
npm run dev
```

브라우저에서 터미널에 표시된 로컬 주소를 엽니다. `npm run build`로 배포 파일을 생성하고 `npm test`로 회의와 출퇴근 규칙을 검증합니다.

## Vercel 배포

저장소를 Vercel에 연결한 뒤 **Root Directory를 `office`**로 설정합니다. `office` 폴더 자체가 저장소 루트라면 Root Directory는 기본값으로 둡니다.

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- 환경 변수 및 별도 서버: 필요 없음

별도의 `vercel.json` 없이 Vercel 대시보드에서 위 설정을 선택하면 됩니다. 시뮬레이션 상태는 각 방문자의 브라우저에서 독립적으로 실행되며, 새로고침하면 초기화됩니다.

## 사용법

- 출근하기: 영업팀·인사팀·회계팀·개발팀·기획팀마다 팀원 4명과 팀장 1명, 대표까지 총 26명이 순차 입장합니다.
- 회의: 출근당 각 팀이 한 번씩만 회의합니다. 팀 순서는 무작위이며 A·B 회의실에서 최대 두 팀이 동시에 진행합니다. 다섯 명이 모두 도착하면 약 20초간 회의합니다. 다섯 팀의 회의가 모두 끝나면 대표와 각 팀 팀장 5명, 총 6명이 모여 마지막 회의를 한 번 진행합니다. 이후에는 업무·협업·휴식만 계속하며, 퇴근 후 다시 출근해야 회의 일정이 새로 생성됩니다.
- 직원: 머리 모양·옷·체형·안경·액세서리를 다르게 구성하고, 머리 위 말풍선에 이름·직책·현재 업무를 표시합니다. 업무, 동료 협업, 별도 탕비실에서 커피 휴식을 반복하고 대표는 회의를 참관합니다.
- 배치: 팀별 파티션, 마주 보는 4인 책상과 별도 팀장 자리, 유리벽과 자동 미닫이문으로 분리된 6인 회의실·대표실·탕비실을 제공합니다. 직원은 문과 통로를 따라 이동합니다.
- 퇴근하기: 미완료 회의를 취소하고 모든 직원을 출구로 이동시킵니다.
- 마우스 왼쪽 드래그: 시점 회전. 휠 버튼(가운데 버튼) 또는 오른쪽 버튼 드래그: 바닥면을 따라 위치 이동. 스크롤: 확대/축소. 직원 왼쪽 클릭: 현재 상태.
- 전체화면: 사무실 상단의 전체화면 버튼으로 3D 영역만 확대합니다. 전체화면 닫기 또는 Esc로 복귀하며, 출퇴근과 시점 초기화도 전체화면 안에서 사용할 수 있습니다. 브라우저 전체화면 기능을 사용할 수 없으면 페이지 내부 확장 화면으로 동작합니다.
- 하단 버튼: 일시정지 및 1·2·4배속.

행동과 이름은 `src/simulation.js`, 공통 좌표와 이동 경로는 `src/layout.js`, 사무실과 캐릭터 외형은 `src/scene.js`에서 수정합니다. 화면과 사무실은 더스티 로즈·모브·아이보리 계열입니다. 시간은 실제 시각과 별개인 가상 시간이며, 상태는 브라우저를 새로 고치면 초기화됩니다.
