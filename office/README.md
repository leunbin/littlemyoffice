# 우리의 작은 회사

React + Three.js 기반 3층 오피스 시뮬레이션입니다. 서버·로그인 없이 동작하며 업무와 지원자·방문 기업 정보는 가상 데이터입니다.

## 실행

```sh
npm install
npm run dev
```

`npm run build`로 배포 파일을 만들 수 있습니다. Vercel에서는 이 폴더를 Root Directory로 선택하고 Build Command `npm run build`, Output Directory `dist`를 사용합니다.

## 회사와 공간

- 현재 8개 부서와 대표·안내 담당·식당·카페 직원, 총 52명이 있습니다.
- 지하 1층: 뷔페 식당·유리벽 카페·영양사실·조리사 탈의 및 휴게실. 승강장 뒤쪽을 식사 공간으로 확장해 총 48석을 제공합니다.
- 1층: 영업·인사·경영지원 업무 구역과 넓은 공용 홀·안내 데스크·라운지를 불투명 벽과 양문 출입문으로 구분합니다. 건물 출입문은 1층에만 있습니다.
- 2층: 개발·기획·디자인, 프로젝트룸, 엘리베이터 홀 옆 탕비실. 기존 협업 공간과 제품 협업 워크숍은 제거했습니다.
- 3층: 회계·마케팅, 12석 대회의실, 집무·접견 구역을 분리한 회장실, 정원·전략 라운지와 엘리베이터 홀 옆 탕비실. 회장실은 짙은 목재 책상·책장과 가죽 소파 접견석으로 구성합니다.
- 엘리베이터 2대는 모든 층의 같은 위치에서 한쪽 콘크리트 벽에 나란히 배치합니다. 지하와 2·3층은 작은 승강장과 동쪽 접근 통로를 남기고 나머지를 식당·업무 공간으로 활용합니다.
- 엘리베이터 앞 바닥 표시는 대기 위치입니다. 현재 위치·운행 방향·목적지·예약 인원을 비교해 엘리베이터를 배정하고, 같은 목적지 승객을 최대 12명씩 태웁니다.
- 운행 현황에 탑승·대기 인원과 평균 대기 시간을 표시합니다. 시간은 시뮬레이션 기준이며, 대기 위치 도착부터 탑승까지 측정합니다.

## 부서 확장

`src/departments.js`의 `DEPTS`에 `name`, `color`, `tasks`, `names`를 추가하면 빈 팀 공간에 자동 배치합니다. `names`의 마지막 사람이 팀장이며 팀장 포함 최대 5명입니다. 선택적으로 `floor: 0`, `1`, `2`를 지정할 수 있고 해당 층이 차면 다른 빈 층을 사용합니다.

1층 3개, 2층 4개, 3층 3개로 총 10개 부서를 수용합니다. 현재 8개 부서 외에 2개 공간이 남습니다. 2층의 기존 탕비실 자리는 새 부서용 공간이며, 3층의 같은 자리는 확대된 회장실에 포함됩니다. 2·3층 탕비실은 이전 FUTURE TEAM 자리에 있고 바닥 표시 영역은 8×7입니다. 가구는 100% 크기로 배치하고 싱크대·수납장은 바닥 끝의 뒤 벽 앞에 붙였습니다. 홀 쪽 벽은 회사 출입문 문틀 끝에 맞춰 시작합니다. 3층 전략 라운지도 새 부서가 들어오면 책상 공간으로 전환됩니다.

11번째 부서나 팀당 6명 이상을 추가하려면 `src/layout.js`의 팀 공간·좌석 및 층 구조도 확장해야 합니다. 공간을 초과하는 설정은 오류로 알립니다.

## 일정과 행동

- 1·2층 회의실은 각각 6석이고, 3층은 기존 회의실 두 개를 합친 12석 대회의실입니다. 대표·팀장 회의는 3층 대회의실에서 전원이 한 번에 참석합니다.
- 내부 회의와 외부 기업 미팅은 가상 시각 기준 1시간 간격으로 배정합니다. 12시에는 외부 기업 미팅을 진행하며 지연 시에도 회의 시작 간격을 유지합니다.
- 면접은 출근마다 1~3건 예약합니다. 지원자 접수와 인사팀 안내 후 대표·인사팀장·채용 부서 팀장이 면접합니다.
- 외부 기업 미팅은 정장 차림 한빛테크 방문객 3명과 영업팀장·무작위 팀원 2명, 총 6명이 1층 회의실 B에서 진행합니다.
- 외부 방문객은 라운지에 입장해 기다립니다. 서지은이 라운지로 마중 나가 방문 목적을 묻고, 확인 후 데스크에 복귀해 영업팀 담당자에게 연락합니다. 영업 담당자가 라운지로 나와 인사한 뒤 방문객을 회의실로 안내합니다. 미팅 후 방문객은 출입문으로 퇴장합니다.
- 오피스 투어는 인사팀 안내 직원과 참여 직원이 1층 로비·업무 구역 → 2층 제품 업무 구역 → 3층 회장실·정원을 실제로 이동합니다.
- 경영 전략 논의는 STRATEGY LOUNGE, 생일 파티와 출시 발표는 프로젝트룸에서 진행합니다.
- 프로젝트는 기획·디자인·개발·마케팅 등 담당 팀을 거쳐 인계됩니다. 직원의 성격·에너지에 따라 업무·협업·휴식 행동이 달라집니다.
- 퇴근하면 미완료 일정을 취소하고 직원과 방문객이 모두 퇴장합니다.

## 화면과 저장

왼쪽 드래그로 회전, 가운데·오른쪽 드래그로 이동, 스크롤로 확대합니다. 직원을 선택해 따라가기를 누르거나 대표 PC에서 이름을 누르면 카메라와 층이 직원을 따라갑니다. Esc 또는 시점 초기화로 추적을 해제합니다.

전체화면에서도 건물 전체 보기·1층·2층·3층 버튼을 사용할 수 있습니다. 대표 PC는 현황·채용·프로젝트·일정·회의·직원 탭으로 구성되며 패널 내부에서 스크롤합니다.

저장 버튼은 제공하지 않습니다. 10초마다 자동 저장하고, 페이지를 떠나거나 숨길 때도 저장합니다. 새로고침하면 같은 브라우저에 저장된 시뮬레이션을 자동으로 불러옵니다. 방문객 응대 단계·직원 이동·회의·프로젝트 진행 상태도 함께 저장합니다.

시뮬레이션은 `src/simulation.js`, 좌표와 이동 경로는 `src/layout.js`, 사무실·인물은 `src/scene.js`, 층별 인테리어는 `src/interiors.js`, 화면은 `src/main.jsx`에서 수정합니다.
