# 우리의 작은 회사

React + Three.js 기반 3층 오피스 시뮬레이션입니다. 서버·로그인 없이 동작하며 업무와 지원자·방문 기업 정보는 가상 데이터입니다.

## 실행

```sh
npm install
npm run dev
```

`npm run build`로 배포 파일을 만들 수 있습니다. Vercel에서는 이 폴더를 Root Directory로 선택하고 Build Command `npm run build`, Output Directory `dist`를 사용합니다.

## 회사와 공간

- 직원 37명: 영업·인사·회계·개발·기획·디자인·마케팅 각 5명, 대표 이정우, 안내 담당 서지은.
- 1층: 영업·인사 업무 공간, 면접·외부 미팅 회의실, 탕비실, 안내 데스크와 로비 라운지. 불투명 벽과 출입문으로 로비에서 업무 공간을 가립니다.
- 2층: 개발·기획·디자인, COLLABORATION LAB, 프로젝트룸, 탕비실.
- 3층: 회계·마케팅, 대표실, STRATEGY LOUNGE, 정원과 탕비실.
- 각 층에 남녀 화장실과 반투명 가림막 전실을 배치했습니다. 직원은 같은 층 화장실 이동 → 이용 → 손 씻기 → 자리 복귀 순서로 행동합니다.
- 출입문과 엘리베이터는 위치를 교환해 같은 외벽선에 맞췄습니다. 1층 출입문은 근처 사람이 있으면 자동으로 열리는 유리문입니다. 라운지의 층별 안내판은 제거했습니다.
- 건물 전체 보기는 3개 층이 위아래로 겹친 3D 화면입니다. 별도의 2D 층별 구조도 기능은 없습니다.

## 일정과 행동

- 내부 회의와 외부 기업 미팅은 가상 시각 기준 1시간 간격으로 배정합니다. 12시에는 외부 기업 미팅을 진행하며 지연 시에도 회의 시작 간격을 유지합니다.
- 면접은 출근마다 1~3건 예약합니다. 지원자 접수와 인사팀 안내 후 대표·인사팀장·채용 부서 팀장이 면접합니다.
- 외부 기업 미팅은 정장 차림 한빛테크 방문객 3명과 영업팀장·무작위 팀원 2명, 총 6명이 1층 회의실 B에서 진행합니다.
- 외부 방문객은 라운지에 입장해 기다립니다. 서지은이 라운지로 마중 나가 방문 목적을 묻고, 확인 후 데스크에 복귀해 영업팀 담당자에게 연락합니다. 영업 담당자가 라운지로 나와 인사한 뒤 방문객을 회의실로 안내합니다. 미팅 후 방문객은 출입문으로 퇴장합니다.
- 오피스 투어는 인사팀 안내 직원과 참여 직원이 1층 로비·업무 구역 → 2층 제품 업무 구역·협업 라운지 → 3층 대표실·정원을 실제로 이동합니다.
- 제품 워크숍은 COLLABORATION LAB, 경영 전략 논의는 STRATEGY LOUNGE, 생일 파티와 출시 발표는 프로젝트룸에서 진행합니다.
- 프로젝트는 기획·디자인·개발·마케팅 등 담당 팀을 거쳐 인계됩니다. 직원의 성격·에너지에 따라 업무·협업·휴식 행동이 달라집니다.
- 퇴근하면 미완료 일정을 취소하고 직원과 방문객이 모두 퇴장합니다.

## 화면과 저장

왼쪽 드래그로 회전, 가운데·오른쪽 드래그로 이동, 스크롤로 확대합니다. 직원을 선택해 따라가기를 누르거나 대표 PC에서 이름을 누르면 카메라와 층이 직원을 따라갑니다. Esc 또는 시점 초기화로 추적을 해제합니다.

전체화면에서도 건물 전체 보기·1층·2층·3층 버튼을 사용할 수 있습니다. 대표 PC는 현황·채용·프로젝트·일정·회의·직원 탭으로 구성되며 패널 내부에서 스크롤합니다.

저장 버튼은 제공하지 않습니다. 10초마다 자동 저장하고, 페이지를 떠나거나 숨길 때도 저장합니다. 새로고침하면 같은 브라우저에 저장된 시뮬레이션을 자동으로 불러옵니다. 방문객 응대 단계·직원 이동·회의·프로젝트 진행 상태도 함께 저장합니다.

시뮬레이션은 `src/simulation.js`, 좌표와 이동 경로는 `src/layout.js`, 사무실·인물은 `src/scene.js`, 층별 인테리어는 `src/interiors.js`, 화면은 `src/main.jsx`에서 수정합니다.
