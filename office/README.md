# 우리의 작은 회사

React + Three.js 기반의 로컬 상태 3D 오피스 시뮬레이션입니다. 서버, AI, 로그인 없이 동작합니다.

## 실행

```sh
npm install
npm run dev
```

브라우저에서 터미널에 표시된 로컬 주소를 엽니다. `npm run build`로 배포 파일을 생성하고 `npm test`로 회의와 출퇴근 규칙을 검증합니다.

## Vercel 배포

저장소를 Vercel에 연결한 뒤 **Root Directory를 `office`**로 설정합니다. `office` 폴더 자체가 저장소 루트라면 Root Directory는 기본값으로 둡니다.

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- 환경 변수 및 별도 서버: 필요 없음

별도의 `vercel.json` 없이 Vercel 대시보드에서 위 설정을 선택하면 됩니다. 시뮬레이션 상태는 각 방문자의 브라우저에서 독립적으로 실행되며, 새로고침하면 초기화됩니다.

## 확장된 회사

- 총 37명: 영업·인사·회계·개발·기획·디자인·마케팅 7개 팀(팀원 4명, 팀장 1명)과 대표, 상주 안내 담당 1명입니다.
- 1층은 영업·인사와 방문객 라운지, 2층은 개발·기획·디자인과 프로젝트 공간, 3층은 회계·마케팅·대표실과 정원입니다. 각 층에 회의실 A·B와 탕비실이 있습니다.
- 층 버튼으로 사무실을 전환하고, 건물 전체 보기에서는 실제 1·2·3층 도면이 수직으로 겹쳐 표시되며 층을 클릭해 들어갑니다. 직원은 엘리베이터 위치에서 층을 전환합니다.
- 출근마다 팀별 회의 한 번과 대표·팀장 8명의 마지막 회의를 생성합니다.
- 직원 클릭 후 따라가기를 누르면 카메라와 층이 직원을 따라갑니다. 대표 PC의 직원 이름을 눌러도 추적합니다. Esc 또는 시점 초기화로 해제합니다.
- 대표 PC는 현황·채용·프로젝트·일정·회의·직원을 한 탭 메뉴로 제공하며 화면 안에서 내용만 스크롤합니다. 실시간 회의 참석자, 실제 인사팀 행동, 가상 지원자 이력서·면접 일정, 프로젝트 담당 팀·진행률·인계 기록, 일일 이벤트를 확인합니다.
- 면접은 출근마다 1~3건 예약합니다. 지원자가 1층에 도착하면 인사팀 팀원이 마중 나와 회의실 A로 안내합니다. 대표·인사팀장·채용 부서 팀장이 모두 도착하면 면접을 시작하며, 종료 후 지원자는 퇴장합니다. 회의실과 참석자가 사용 중이면 기다립니다. 퇴근하면 미완료 면접을 취소하고 방문객도 퇴장합니다.
- 직원의 성격과 에너지에 따라 휴식·협업 빈도가 달라집니다. 직원 정보 카드에서 기분과 담당 업무를 확인합니다.
- 홈페이지 개편과 고객 서비스 프로젝트가 기획·디자인·개발·마케팅 등을 거쳐 인계됩니다. 담당 팀에서 실제 근무 가능한 직원 수에 따라 작업이 진행됩니다.
- 신입 투어, 점심, 발표·간식 이벤트에 직원들이 이동합니다. 층별 라운지·제품 보드·정원과 시간에 따른 조명 변화를 제공합니다.
- 10초마다 브라우저에 자동 저장하며 저장 버튼으로 즉시 저장합니다. 새로고침하면 진행 상태를 복원합니다. 서버나 실제 회사 데이터 연동은 없으며 이력서와 업무는 가상 데이터입니다.

## 조작

왼쪽 드래그로 회전, 가운데·오른쪽 드래그로 이동, 스크롤로 확대합니다. 전체화면과 일시정지, 1·2·4배속을 지원합니다. 출퇴근은 수동으로 진행합니다.

시뮬레이션은 `src/simulation.js`, 공통 좌표·이동 경로는 `src/layout.js`, 외형은 `src/scene.js`, 대표 PC와 화면은 `src/main.jsx`에서 수정합니다. `npm test`는 회의, 면접 안내·참석·퇴장, 프로젝트, 이벤트, 저장 복원을 검증합니다.

이전 저장 데이터의 깨진 직원·지원자 이름은 현재 명단의 한글 이름으로 자동 복구합니다.

1층 로비는 엘리베이터 옆 안내 데스크와 웰컴 라운지부터 기존 탕비실 자리까지 이어집니다. 방문객 라운지는 없애고 그 자리에 탕비실을 옮겼습니다. 불투명 벽·자동 출입문·엇갈린 가림벽으로 업무 공간의 시야를 차단하며 직원과 지원자는 출입 동선을 따라 이동합니다.

지원자 도착 시 안내 직원을 먼저 배정합니다. 대표·인사팀장·채용 부서 팀장은 진행 중인 회의가 끝나면 우선 합류하고, 새 회의·휴식으로 빠지지 않습니다. 대표 PC 채용 탭에서 실제 대기 사유를 확인할 수 있으며 이전 저장 데이터의 멈춘 안내 상태도 복구합니다.

안내 데스크에는 서지은 안내 담당이 상주합니다. 방문객이 접수하면 인사팀에 연락하고, 인사팀 직원이 마중 나와 면접실로 안내합니다. 안내 담당은 일반 협업·팀 회의·단체 이벤트에 차출되지 않습니다.

대표 이정우의 기본 근무지는 3층 대표실이며, 면접 등 일정이 끝나면 엘리베이터를 통해 복귀합니다. 예전 저장 데이터의 대표 근무층과 대표실 좌표도 복구합니다. 각 층 서쪽 빈 공간에는 남녀 화장실을 구분해 배치했습니다(표지·출입문·개별 칸·세면대 포함).

## 층별 인테리어

공통 가구는 오크·웜그레이·그래파이트 계열로 정리하고, 업무 공간에는 직조 카펫·수납장·개인 서랍·흡음 파티션·배선 트레이·팔걸이 사무용 의자를 배치했습니다. 창호 프레임, 구조 기둥, 선형 조명, 바닥 구획과 층별 사인으로 공간을 구분합니다.

- 1층: 석재 느낌의 로비, 우드 슬랫 안내 카운터, 층별 안내판, 고객 대기 공간, 인사·운영 보드와 복합기.
- 2층: 개발팀 듀얼 모니터, 디자인 리뷰 보드, 협업 소파 라운지, 프로젝트 보드와 자료 서가.
- 3층: 경영지원 서가·수납장, 전략 라운지, 우드 월 대표실·데스크 패드·미팅 소파, 정원 데크.

회의실에는 발표 화면·카메라·메모지·컵을 추가했습니다. 인테리어 코드는 `src/interiors.js`로 분리했으며, 기존 좌석·층 이동·로비 보안·면접 동선을 유지합니다.

모든 층 화장실 앞은 보드·수납·복합기·정원 등을 다른 위치로 옮겨 비우고, 반투명 가림막으로 전실을 구분했습니다. 가림막 남쪽의 열린 통로로 출입하며 화장실 문으로 이어지는 이동 경로를 제공합니다.

직원은 근무 중 주기적으로 같은 층 화장실을 이용합니다. 화장실별 두 자리의 이용 인원을 관리하며, 이동 → 이용 → 세면대 이동 → 손 씻기 → 자리 복귀 순서로 진행합니다. 회의·면접·단체 일정과 동시에 수행하지 않으며, 이용 중에는 캐릭터를 숨기고 직원 상태에는 이용 상태를 표시합니다. 상주 안내 담당은 데스크를 유지합니다.

모든 층 엘리베이터는 가로 방향으로 90도 회전 배치하고 로비 쪽으로 출입하도록 이동 지점을 맞췄습니다.
