# Little My Office

React와 Three.js로 만든 26인 가상 회사 시뮬레이션입니다.

## 실행

```sh
cd office
npm install
npm run dev
```

## Vercel

- Root Directory: `office`
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- 환경 변수 없음

출퇴근, 팀별 회의, 대표·팀장 회의, 업무·협업·탕비실 휴식을 제공합니다. 각 브라우저에서 독립적으로 동작하며 새로고침하면 상태가 초기화됩니다.

자세한 내용은 [프로젝트 안내](office/README.md)를 참고하세요.
